Tabs

Roving tabindex, arrow-key navigation, and ARIA from bast-ui. Styling is driven by data-selected / data-disabled. Automatic activation follows focus; switch activation-mode="manual" to require Enter/Space.

Overview Usage Coming soon Tabs organize content into panels, showing one at a time. Use the arrow keys to move between tabs — focus wraps around, and Home / End jump to the ends. Give the root a value to control the selection, or leave it off to default to the first enabled tab. Each tab and panel is linked by a matching value. This panel is unreachable — its tab is disabled.
