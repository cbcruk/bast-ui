Accordion

Collapsible items sharing one bast-accordion. Single-expansion by default (open one, the rest collapse); add multiple to allow several open at once. Each header button wires aria-expanded / aria-controls; arrow keys move focus between headers, Home / End jump to the ends. Style with data-open / data-closed / data-disabled.

What is bast-ui? A headless web-component implementation of Base UI primitives, built on FAST — no framework runtime required. How do I style it? Every part exposes data-* attributes instead of internal classes, so you style the parts directly in light DOM. Disabled item You can't reach this — the item is disabled.
