bast-ui

Headless, accessible UI primitives as native web components — a Base UI / Radix-style layer built on FAST.

Live demos, built as a Vite multi-page app (vp dev to run, vp build to ship). Open any card to try the primitive — every page also lists its attributes straight from custom-elements.json.
